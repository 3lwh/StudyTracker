# Study & Task Tracker with Analytics

A full-stack web application designed to help students and developers organize tasks, track study duration, and visualize time allocation across categories in real time.

---

## Tech Stack

* **Frontend:** React, Chart.js, Axios, HTML5/CSS3
* **Backend:** Python, Flask, Flask-CORS
* **Database:** SQLite

---

## Features

* **Task & Study Logging:** Input scheduled tasks alongside estimated completion times.
* **Live Analytics Dashboard:** Dynamic visualization using Chart.js to monitor workload distribution.
* **REST API:** Modular Python Flask backend handling persistent SQLite database operations.
